3. weather - Get current weather for any location. Completely free, no API key. Arguments: {"location": "city name or place"}. Use for: weather, temperature, forecasts, humidity, wind.

6. current_time - Get current local date and time. Arguments: {}. Use for: timestamps, scheduling, time-sensitive queries.
7. create_agent - Create a reusable Python agent and save it to the workspace/agents folder. Use for: building custom scripts, scrapers, calculators, data processors, or any reusable automation. Arguments: {"name": "agent_name", "code": "full python code"}. The name must be a valid filename: letters, numbers, underscores only. The code must be a complete, self-contained Python script. If the agent needs input, it can read sys.argv[1] which will be a path to a temporary JSON input file.
8. run_agent - Run a previously created agent from the workspace/agents folder. Use for: reusing saved agents to perform tasks without rewriting code. Arguments: {"name": "agent_name", "input": "optional input data (string or object)"}. If input is provided, it is saved to a temporary JSON file and the file path is passed as the first command-line argument. The agent can read this file to get its input. Agents created with create_agent persist on disk and can be reused in future conversations. If the agent does not exist, you MUST create it first with create_agent.
